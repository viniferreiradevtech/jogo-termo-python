# jogo-termo-python

# Termo em Python

Projeto desenvolvido para reproduzir a mecânica principal do jogo **Termo**, utilizando Python para praticar conceitos fundamentais de lógica de programação.

## Sobre o projeto

O jogo consiste em descobrir uma palavra secreta de cinco letras em até seis tentativas. A cada palpite, o programa fornece dicas visuais para ajudar o jogador a encontrar a resposta correta.

Este projeto tem finalidade **educacional**, com foco na prática de programação e na compreensão de estruturas lógicas.

## Tecnologias utilizadas

- **Python 3** — linguagem utilizada no desenvolvimento.
- **`input()` e `print()`** — entrada de dados e exibição de resultados no terminal.
- **Estruturas condicionais** — verificação das letras e validação da palavra.
- **Laços de repetição** — controle das tentativas e análise dos caracteres.
- **Emojis** — indicadores visuais para representar as dicas.

## Como funciona

- O jogador tem **6 tentativas** para descobrir a palavra secreta.
- A palavra deve conter exatamente **5 letras**.
- 🟩 Letra correta na posição correta.
- 🟨 Letra presente na palavra, mas em outra posição.
- ⬛ Letra que não está presente na palavra.
- Ao acertar, o jogo é encerrado. Caso contrário, a palavra correta é revelada ao final das tentativas.

## Como executar

1. Instale o Python 3 em seu computador.
2. Clone o repositório ou baixe os arquivos do projeto.
3. Abra o terminal na pasta do projeto.
4. Execute o comando:

```bash
python jogo.py
```

**Observação:** o nome `jogo.py` deve corresponder ao nome do arquivo Python existente no repositório.
